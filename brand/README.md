# SwiftLoop Brand Kit

This directory is the working SwiftLoop identity kit.

## Start here

- `guidelines.html` — visual and strategic brand guide
- `BRAND-GUIDELINES.md` — LLM-friendly written specification
- `design-tokens.json` — machine-readable design tokens and brand facts
- `logo/` — production SVG and PNG logo assets
- `social/` — exported social media assets
- `invoice-generator.html` — branded quote and invoice tool
- `business-card-v2.html` — branded business card preview and print tool

## Source of truth order

1. `css/style.css` for the current website implementation
2. `brand/design-tokens.json` for portable semantic values
3. `brand/BRAND-GUIDELINES.md` for usage rules and voice
4. `brand/guidelines.html` for visual examples

When these disagree, verify the live website implementation before propagating a change through the kit.
